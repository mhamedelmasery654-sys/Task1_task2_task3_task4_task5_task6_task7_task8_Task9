- نظام التشغيل: Windows
- Node.js: v24.21.0
- npm: 11.19.0
- PostgreSQL: مثبت محليًا وبخدمة تعمل بشكل صحيح
- المشروع: task-8-blog-api

## خطوات التنفيذ
1. تثبيت الاعتماديات باستخدام `npm ci` بنجاح.
2. إنشاء ملف `.env` محليًا من ملف `.env.example` لدعم PostgreSQL وJWT.
3. التحقق من توفر PostgreSQL والاتصال المحلي.
4. تشغيل الخادم باستخدام `node server.js`.
5. اختبار المسارات الأساسية للـ API عبر طلبات HTTP مباشرة، مثل:
   - `/health`
   - `/auth/register`
   - `/auth/login`
   - `/auth/me`
   - `/posts`
   - `/posts/search`
   - `/posts/:id`
   - `/admin/users`

## أوامر التحقق التي تم تشغيلها

npm ci
